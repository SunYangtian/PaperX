1. 定位

NeoVerse 是 reconstruction + generation 混合式 4D world model。它从野外单目视频中重建 4DGS，再把 4DGS 在 novel trajectory 下渲染成 degraded conditions，交给视频生成模型修复和补全。

  • 核心目标：让 4D world model 能利用大规模 in-the-wild monocular videos。
  • 核心表示：dynamic 4D Gaussians。
  • 核心生成方式：degraded rendering conditioned video generation。

2. Pose-Free Feed-Forward 4DGS Reconstruction

重建模型基于 VGGT，加入 bidirectional motion-encoding branch，并直接预测 4D Gaussian attributes。

  • 每个 Gaussian 包含 position、opacity、rotation、scale、SH、lifespan、forward/backward velocity 和 angular velocity。
  • Forward branch 建模 t -> t+1，backward branch 建模 t -> t-1。
  • 训练时只输入 sparse keyframes，但用 bidirectional motion 插值 non-keyframes 并监督全部帧。
  • 损失包括 RGB、camera、depth、motion 和 opacity regularization。

3. Reconstruction-Guided Video Generation

NeoVerse 用 Wan-T2V 14B + Rectified Flow 做视频生成。4DGS 渲染结果作为 control condition，原始视频作为 target。

  • Degraded conditions 包括 RGB renderings、depth maps、binary masks 和 Plucker embeddings。
  • Conditions 通过 control branch 注入视频生成模型。
  • 训练时冻结视频生成主干，只训练 control branch。
  • 目标是让模型从低质量 novel-view rendering 中恢复高质量、时空一致的视频。

4. 训练流程

  • Reconstruction training：输入最长边 560；每次采样 2 <= N <= 8 keyframes 和中间 target frames。
  • Generation training：固定分辨率 336 x 560，长度 81 frames。
  • 每个 video clip 随机采样 11 ~ 21 keyframes 做 on-the-fly 4DGS reconstruction。
  • 使用 32 张 A800；reconstruction 150K iterations，generation 50K iterations。
  • 数据包括 18 个公开数据源，以及超过 1M 自收集 monocular videos。

5. Memory / Camera Control

NeoVerse 的 memory 是显式 4D representation，而不是 Transformer memory tokens。

  • 4DGS 保存 scene geometry、appearance 和 motion。
  • 推理时可用 global motion tracking 分离 static / dynamic Gaussians。
  • Static part 跨全部帧聚合，dynamic part 只聚合附近帧，避免 motion drift。
  • Camera control 来自 novel trajectory 下的 4DGS rendering 和 Plucker camera condition。

6. 蒸馏与加速

NeoVerse 没有提出自己的 DMD teacher-student 蒸馏流程。它的生成训练冻结 Wan-T2V 主干、只训练 control branch，因此可以兼容现成 video diffusion distillation LoRA 来加速生成。

  • 主要贡献不是 distillation，而是 scalable monocular-video training pipeline。
  • 可把 Wan-T2V 14B 视为冻结 base generator。
  • Control branch 设计让模型能复用外部加速 LoRA。
