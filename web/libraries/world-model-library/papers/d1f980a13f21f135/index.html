1. Teacher / Base Model 训练

HY-World 1.5 使用 WorldPlay 作为实时交互世界模型。起点是一个 bidirectional video diffusion model，随后被改造成 chunk-wise autoregressive diffusion model，用于 next chunk prediction。

  • 训练数据为 320K curated video clips：170K AAA games、60K real-world 3D、50K synthetic 4D、40K real-world video。
  • 标注包括 text captions、continuous camera poses 和 discrete action signals。
  • 基础视频模型使用 3D VAE + DiT，在 latent space 里用 flow matching 训练。
  • AR 改造：1 chunk = 4 latents = 16 frames；训练时不同 chunk 加不同噪声，self-attention 改为 block-causal。
  • Middle-training 将 Dual Action Representation 和 Reconstituted Context Memory 接入 AR diffusion model。
  • WorldCompass RL post-training 进一步强化动作跟随和视觉质量。

2. Student 蒸馏：Context Forcing

Context Forcing 解决的是 memory-aware distillation 中的条件分布错位：bidirectional teacher 和 autoregressive student 如果看到不同 memory context，普通 DMD 的 score 监督会失效。

  • Student self-rollout 4 chunks，每个 chunk 生成前都从已知历史中重构 memory context。
  • Teacher 是 memory-augmented bidirectional video diffusion model。
  • Teacher context 由 student rollout 对应的 memory context 构造，但 mask 掉当前要监督的 4 个 chunks。
  • 这样 teacher/student 都在尽量一致的 memory 条件下计算 distribution matching loss。
  • 蒸馏后支持 4 denoising steps，同时保持 long-term consistency 并减少 error accumulation。
  • 最终系统报告可进行 24 FPS long-horizon streaming generation。

3. Action 注入机制

HY-World 1.5 使用 Dual Action Representation，把离散键鼠信号和连续 camera pose 同时注入模型。

  • Discrete action：keyboard / mouse inputs 先编码为 action embedding，再经 zero-initialized MLP 投影到 timestep embedding，用于调制 DiT blocks。
  • Continuous pose：rotation / translation matrix 通过 PRoPE 注入 self-attention。
  • PRoPE 使用由 camera intrinsics / extrinsics 派生的 Dproj，增加一个 projective attention 分支。
  • 每个 self-attention block 的输出是原始 3D RoPE attention 加上 zero-init 的 projective attention。
  • 离散动作提供跨场景尺度的鲁棒控制；连续 pose 提供精确空间定位，并服务于 spatial memory retrieval。

4. Memory 机制

Reconstituted Context Memory 在每次生成新 chunk 时动态重建 context，而不是把全部历史帧都送进模型。

  • Temporal memory：最近 L 个 chunks，用于短期运动平滑。
  • Spatial memory：从非相邻历史帧中采样，用于重访旧区域时保持几何和外观一致。
  • Spatial retrieval 使用 geometric relevance score，结合 FOV overlap 和 camera distance。
  • Temporal Reframing 会丢弃真实绝对时间 index，重新分配 positional encoding，把几何相关的长程 memory 在 RoPE 距离上拉近。
  • 推理阶段继续逐 chunk 重构 memory，并用 KV cache 减少重复计算。
