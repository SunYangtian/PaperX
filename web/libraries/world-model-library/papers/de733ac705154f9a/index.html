1. 定位

Lyra 2.0 是 camera-trajectory controlled generative reconstruction 系统：从单张输入图开始，用户指定长程相机轨迹，模型生成 3D-consistent walkthrough video，并进一步重建为 3DGS 和 mesh。

  • 核心问题一：spatial forgetting，相机回看旧区域时模型忘记历史结构。
  • 核心问题二：temporal drifting，自回归生成误差逐步累积。
  • 核心设计：per-frame 3D cache 只用于 routing 和 correspondence，不直接作为强渲染约束。

2. 视频模型训练

Lyra 2.0 使用 DiT-based latent video diffusion，基础 VAE 为 Wan 2.1 VAE。完整训练后的 35-step video model 可视为 DMD teacher。

  • 训练数据：DL3DV 的 10K long video clips，每个视频采样约 1,000 frames。
  • 标注：ViPE camera poses、Depth Anything V3 depth、Qwen3-VL-8B-Instruct captions。
  • 30% I2V：单张初始图生成前 L=80 连续帧。
  • 70% autoregressive chunk training：history window 作为 context，下一个 L=80 frames 作为 target。
  • Self-augmentation 训练让模型在 imperfect history context 下仍向 clean target denoise。

3. 相机控制 / Action 注入

Lyra 2.0 的 action 不是 WASD，而是用户指定的 camera trajectory。模型用 depth-based warping 和 Plucker ray injection 共同控制视角。

  • Depth warping：把最近帧按 depth 和目标相机位姿 forward-warp 到目标视角，作为强几何提示。
  • Plucker ray：为每个像素计算 6D ray coordinate，经 MLP 投影后加到 DiT token features。
  • Depth warping 在大视角变化时会丢失像素，Plucker ray 提供额外 dense pose hint。

4. Memory：3D Cache + Spatial Slots

Lyra 2.0 的 memory 是 per-frame 3D cache。每帧独立保存 depth、camera parameters 和 downsampled point cloud，避免把误差融合进单个 global point cloud。

  • Geometry-aware retrieval：把历史点云投影到 target view，按 visible points 数量选择相关 history frames。
  • 推理时 greedy maximize coverage，选择覆盖最多未覆盖 target pixels 的历史帧。
  • Retrieved frames 被编码成 spatial slots，与 temporal FramePack slots 和 generation tokens 一起进入 DiT self-attention。
  • Canonical coordinate + depth 被 forward-warp 到 target view，经 MLP 编码后注入每个 transformer block 的 self-attention。
  • 它 warp 几何坐标而不是 RGB，避免把 RGB warp 的空洞和边界伪影直接复制进生成结果。

5. DMD 蒸馏

Lyra 2.0 训练了 distilled model 用于加速交互式使用。

  • Teacher：完整 35-step video model。
  • Student：DMD 蒸馏到 4 denoising steps。
  • 同时蒸馏 classifier-free guidance，推理时不再需要 conditional / unconditional 双 forward。
  • 蒸馏期间保留 self-augmentation，维持对 autoregressive error accumulation 的鲁棒性。
  • 论文报告 per-step generation time 约减少 13x，4-step DMD 质量接近 35-step full model。

6. 3D Reconstruction

生成视频会被转成 explicit 3D assets。

  • 3DGS：基于 Depth Anything V3，修改 Gaussian DPT head 降低 Gaussian 数量。
  • 用 Lyra 2.0 生成场景 fine-tune DAv3，使其适应 generated video 的轻微多视角不一致。
  • Mesh：用 OpenVDB hierarchical sparse grid，近处细网格、远处粗网格，marching cubes 提取并简化。
  • 输出可用于 interactive viewer、VR 和 NVIDIA Isaac Sim。
