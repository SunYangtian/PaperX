1. 定位

InSpatio-WorldFM 是 real-time generative frame model。它不按 video window 生成，而是每次独立生成目标视角单帧，用空间条件保持多视角一致性。

  • 目标：低延迟 real-time spatial inference。
  • 核心条件：reference image、reference pose、target pose、target-view point cloud rendering。
  • 核心取舍：减少视频窗口延迟，但牺牲一部分连续帧 temporal stability。

2. 三阶段训练

  • Stage I Pre-training：选择 PixArt-Sigma 作为高效 text-to-image DiT backbone。
  • Stage II Middle-training：把 image generator 转成 controllable frame model with spatial memory。
  • Stage III Post-training：用 DMD 蒸馏成 few-step generator，支持 consumer-grade GPU 实时交互。

训练 pair 来自 public videos、自采视频和 UE synthetic data。真实视频中随机采样 16 帧，4 帧作为 reference group 构建 global point cloud，12 帧作为 targets。合成数据提供精确 pose/depth，用于有限步 finetuning 提升几何稳定性。

3. Camera Control / Action 注入

这里的 action 是 user-defined camera motion / target pose，而不是键鼠离散动作。

  • 输入沿 width 拼接：noisy target latent、point cloud rendering、reference image。
  • 三者经 shared patch embedding 进入 self-attention-only DiT。
  • Camera pose 注入比较了 Plucker ray、PRoPE、pure parametric injection。
  • 最终采用 PRoPE，因为它直接调制 Q/K/V attention，而不是只做 additive embedding。

4. Hybrid Spatial Memory

Memory 由 explicit anchors 和 implicit memory 组成。

  • Explicit anchor：target viewpoint 下的 point cloud rendering，提供 coarse 3D structure 和全局几何 prior。
  • Implicit memory：reference image + reference pose，提供 fine-grained appearance details。
  • 两者都通过 self-attention 与 target latent 交互，不使用 cross-attention 分支。
  • 训练时使用 progressive condition injection 和 random anchor masking，防止模型过度依赖 point cloud anchor。

5. 2-step DMD

Post-training 用 DMD 把 middle-trained multi-step frame model 蒸馏成 few-step generator。

  • Frozen base model 估计 real score。
  • Dynamically-updated model 在 generator outputs 上训练，估计 fake score。
  • Score difference 更新 generator，并用 base deterministic sampler 的 noise-image pairs 加 regression loss 稳定训练。
  • 2-step 优于 1-step：第一步建立 coarse spatial structure，第二步恢复 fine details。
  • 1000-step schedule 下，最佳中间点为 t_mid=200。
  • 512x512：H-series GPU 约 25 FPS，RTX 4090 约 10 FPS。

6. 限制

  • 动态内容生成仍不稳定。
  • 历史 memory 依赖 offline multi-view / panorama observations，在线扩展范围有限。
  • 单帧生成缺少连续帧 temporal constraint，交互时可能出现 frame jitter。
