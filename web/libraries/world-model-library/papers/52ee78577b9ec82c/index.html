1. Teacher / Base Model 训练

Matrix-Game 3.0 的 teacher 来自 memory-augmented bidirectional DiT base model。论文强调 teacher、critic、student 保持统一 bidirectional architecture，避免异构 student 带来的不稳定。

  • 5B base 基于 Wan2.2-TI2V-5B，action modules 集成在前 15 个 DiT blocks。
  • Interactive base training：80% 概率用 4 个 past-frame latents + 10 个 current-frame noisy latents；20% 退化为 action-conditioned I2V。
  • Error-aware training：维护 error buffer，把预测 residual 注入 history latent，模拟推理时 self-generated history 的误差。
  • Memory-augmented training：5 memory latents + 4 past latents + 10 noisy current latents 一起送入 DiT。
  • 训练集约 4.8M video clips。
  • 28B scale-up 中 high-noise model 负责 action control，low-noise model 负责视觉细节和泛化。

2. Few-step Distillation / 实时化

Distillation 阶段的重点是 training-inference aligned multi-segment rollout。Student 在训练中模拟真实 few-step streaming 推理，而不是只在单个窗口里用干净 GT history。

  • Teacher、critic、student 都从 memory-augmented base model 初始化。
  • Cold-start：前 600 steps 使用 single-segment inference，past frames 用 ground truth，防止 few-step student 初期 collapse。
  • Multi-segment：之后 segment 数 k 从 1 到 6 随机采样，训练 2,400 steps。
  • 当前 segment 的 past frames 来自上一 segment 的尾部。
  • Memory 从在线更新的 memory pool 中按当前 camera viewpoint 检索。
  • 随机停止在某个 segment，把该 segment 送给 teacher 和 critic 做 DMD。
  • 实时部署叠加 INT8 DiT、MG-LightVAE pruning 和 GPU memory retrieval，目标 720p@40FPS。

3. Long-Horizon Memory 机制

Matrix-Game 3.0 的 memory 是显式 camera-aware retrieval，并把 memory、recent history、current noisy latents 放进同一个 DiT self-attention space。

  • Memory 输入：5 memory latents、4 past-frame latents、10 current noisy latents。
  • Camera-aware retrieval：根据 camera pose 和 field-of-view overlap 检索 view-relevant history。
  • Relative Plucker-style geometry：编码 current target 与 selected memory 的相对 camera geometry。
  • Joint self-attention：不使用单独 memory branch，而是让 memory/history/current tokens 在同一个 DiT backbone 中交互。
  • Memory error injection：对 memory 和 history latents 同时注入 residual，训练模型从 imperfect memory 中恢复。
  • Temporal RoPE 改造：加入 original frame index，并用 head-wise perturbed RoPE base 减少远距离 memory 的周期 aliasing。
