1. Teacher Model 训练流程

Teacher 基本对应 Stage II 得到的 middle-trained MoE world model，也就是高质量但非实时的 LingBot-World-Base。

  • Stage I: 从 Wan2.2 14B image-to-video diffusion model 初始化，获得视频先验。
  • Stage II: 训练成 28B MoE bidirectional world model。High-noise expert 负责全局结构，low-noise expert 负责细节。
  • 训练视频长度: curriculum 从 5 秒开始，逐步扩展到 60 秒。
  • 任务: 同时做 image-to-video 和 video-to-video continuation。
  • Action finetuning: Plucker embedding + multi-hot action，经 AdaLN 注入 DiT block；冻结主干，只训练 action adapter。

2. 长视频蒸馏

Stage III 把 bidirectional teacher 转成实时 autoregressive student，即 LingBot-World-Fast。

  • Student 从 teacher 的 high-noise expert 初始化。
  • Full bidirectional temporal attention 改成 block causal attention：chunk 内双向，chunk 间因果。
  • 使用 diffusion forcing：不同 chunk 可有独立 timestep，并选择少量 timestep 作为蒸馏目标。
  • Self-rollout extended horizon training 让 student 在自己的生成分布上训练，缓解 train-test gap。
  • DMD 使用 middle-trained MoE teacher 作为 real score model；fake score model 跟踪 student 分布。
  • 额外 adversarial objective 用真实视频监督，补偿 DMD 和少步采样导致的画质差距。

3. Memory 机制

Lingbot-World 的 memory 是 emergent memory，来自长上下文训练和 attention/KV cache，而不是显式外部记忆模块。

  • 训练上通过 5 秒到 60 秒 curriculum，让模型学习长时序一致性。
  • Video-to-video continuation 逼模型利用历史视频作为隐式状态。
  • Teacher 的 bidirectional attention 支撑全局依赖；Fast student 用 block causal attention 和 KV cache 保留历史 chunk。
  • 示例中，landmarks 离开视野 60 秒后仍保持结构，桥和车辆在视野外仍有合理状态演化。
  • 限制：论文明确承认 memory 不是 explicit storage module，长期仿真仍会 drifting。

4. Action 注入与交互实现

Lingbot-World 不把动作写进文本 prompt，而是在 DiT block 内部加入独立的 action conditioning path。文本主要控制语义和外观，action 控制相机、移动和交互轨迹。

  • 连续动作: camera rotation / 3D transformation 用 Plucker embeddings 表示。
  • 离散动作: W/A/S/D 等键盘输入编码为 multi-hot vector。
  • 融合: 连续动作和离散动作沿 channel dimension 拼接，形成 fused action embedding。
  • 注入: action embedding 通过 AdaLN 转成 scale/shift，调制 DiT block 内 video latent 的 normalized features。
  • 训练: 冻结主 DiT blocks，只训练 action adapter、action projection 和 AdaLN 参数。
  • 交互: 推理时每个 chunk 接收当前用户动作，结合历史 KV cache 生成下一段视频，再更新 cache 进入下一轮。
